# 💡 The Magic Bulb - DOM Manipulation Project

A interactive web application built with HTML, CSS, and Modern JavaScript (ES6) that simulates a dynamic light switch. This project highlights core concepts of DOM manipulation, event handling, and state management.

---

## 🚀 Features
* **Dynamic Image Toggling:** Seamlessly switches between a bulb "ON" and "OFF" state.
* **State Tracking:** Uses JavaScript boolean logic to monitor the current state without relying on unstable DOM strings.
* **Responsive Design:** A clean, minimal user interface designed for both desktop and mobile screens.

---

## 🛠️ Tech Stack Used
* **HTML5:** For the structural layout of the image and toggle button.
* **CSS3:** For centering elements and adding a smooth hover effect to the switch.
* **JavaScript (ES6):** Utilizing `document.querySelector`, `addEventListener`, and conditional loops (`if-else`).

---

## 🧠 Concepts Learned
During the development of this project, I strengthened my logic building on:
1. **DOM Accessing:** Selecting elements safely using class and ID selectors.
2. **Event Listeners:** Capturing user interaction (`click` events) with modern arrow functions.
3. **State Management:** Storing the current state of an application using boolean flags (`true`/`false`) rather than checking absolute URLs or source paths directly from the browser.

---

## ⚙️ How to Run Locally
1. Clone this repository to your local machine.
2. Open the `index.html` file using **Live Server** in VS Code.
3. Click the **Switch** button to experience the magic! ✨
